# java-lotto-precourse


## 기능 요구 사항

간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
1등: 6개 번호 일치 / 2,000,000,000원
2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
3등: 5개 번호 일치 / 1,500,000원
4등: 4개 번호 일치 / 50,000원
5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.


## 구현 할 기능 목록

### 입출력
- [x] 로또 구입 금액 입력 출력
- [X] 로또 당첨 번호 입력 출력
- [x] 보너스 번호 입력 출력
- [x] 발행한 로또 번호 오름차순 출력
- [x] 당첨 내역 출력
- [x] 수익률 출력
- [x] 예외 발생 시 [ERROR] 메시지 출력 후 재입력 처리


### 동작
1. 로또 생성 
- [x] 로또 번호 1~45 범위 내 중복 없이 6개 생성

2. 로또 동작
- [x] 로또 개수 계산하기
    - [x] 입력받은 금액을 바탕으로 구매 가능한 로또 개수 계산
- [x] 로또 생성
  - [x] 1 ~ 45 사이의 중복되지 않는 6개의 숫자 생성
  - [x] 번호 오름차순 정렬
  - [x] 각 로또는 객체로 생성하여 리스트로 저장
- [x] 당첨 번호 처리
  - [x] 쉼표 기준으로 당첨 번호를 분리하고 숫자 리스트로 변환
- [x] 당첨 결과 계산
  - [x] 당첨 번호와 로또 번호를 비교하여 일치 개수 통계를 계산하기
  - [x] 보너스 번호 포함 여부에 따라 등수를 판단하기
- [x] 통계 및 수익률 계산
  - [x] 등수 별 당첨 개수 집계
  - [x] 전체 상금 합계 계산
  - [x] 소수점 둘째 자리까지 반올림 하여 수익률 계산

3. 예외 처리
- [x] 구입금액에 사용자가 잘못된 값을 입력했을때
    - [x] 금액이 1000원 이하 일 때
    - [x] 금액이 1000으로 나누어 떨어지지 않을 때
    - [x] 빈 값이 들어왔을 때
    - [x] 숫자 형태가 아닐 떄
- [x] 보너스 번호 & 당첨 번호에 사용자가 잘못된 값을 입력했을떄
    - [x] 숫자 형태가 아닐때 / 빈 값이 들어왔을 떄
    - [x] 1~45 사이 범위가 아닐 때
    - [x] 당첨 번호가 중복일 때
